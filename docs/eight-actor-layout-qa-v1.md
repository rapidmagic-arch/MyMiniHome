## 3. 실제 확인한 사항
### GitHub 원본 및 정적 검사
- 연결된 GitHub 파일의 장면 JSON 재읽기: **8종**, 오브젝트 클릭 영역 **5종**, 템플릿 **1종**.

- 신규 HTML JavaScript 구문 검사 통과.

### 동작 모의 DOM
- **walk-v0.1 pack 준비 모드**: 걷는 4종만 `walk-v0.1-candidate` 활성화, 나머지 4종 `legacy-gestures` 유지.
- **pack 누락 모드**: 8종 모두 기존 제스처 프레임으로 폴백.
- 캐릭터 버튼 8개 각각 클릭 및 프로필 제목 확인, 오브젝트 5개 선택·닫기 오류 0.
- 420px 뷰포트에서 장면 스크롤 배율(0.52배)과 전체보기 전환 계산 확인.
- 이 검사는 **실제 HTML·JS를 가짜 DOM 환경에서 실행한 로직 검사**이며 시각적 브라우저 검증과 구분됨.

### 실제 Chromium 화면 검증(독립 QA 미러)
- Playwright + Chromium의 **독립 HTML 미러**에 마스터 배경과 ZIP의 실제 PNG를 data URI로 로드, 1440·1024·420px에서 **8종 이미지 8/8 로드 / JS 오류 0건**.
- 1440px에서 곰 클릭 후 이름 확인, 420px에서 전체보기 전환(장면 922px→388px로 폭 축소) 동작 확인.
- 시범 조립은 앵커·크기·가림의 **육안 비교를 위한 보조 자료**일 뿐, GitHub 원본 HTML의 CSS/JS 완전 동등성이나 ChatGPT 호스트 동작을 증명하지 않음.
- QA 스크린샷 및 파일은 이 대화의 `MyMiniHome_scene_8actor_QA_v1` 패키지로 제공. 바이너리 스크린샷은 GitHub에 업로드하지 않았음.

## 4. 발견 위험 및 아직 미완료
- 4종 신규 제자리 프레임(특히 개구리/고슴도치)의 오래된 투명 배경 가장자리에는 **잔상 가능성**. 현재는 검토 수준.
- owl/bear/frog/hedgehog에게 걷기 전용 애니메이션이 없음. 활동 목적상 **idle 제스처**로 구분.
- 장면의 캐릭터 간 정밀 픽셀 충돌, 오브젝트 뒤가림(z-order), 원본 마스터와 캐릭터 디자인 정확도 미승인.
- 실제 ChatGPT Conversation Panel과 네이티브 채팅/프로젝트 링크 미연결. 모든 `link:null` 유지.
- 420px에서 **전체보기는 이미지가 작음**. 확대 모드에서 가로 스크롤로 탐색할 수 있으며 실제 패널 UX는 호스트 검증 필요.
- 기존 배경의 오두막/다리/폭포/연못은 **하나의 정적 이미지**. 동적 물/잎·우체통 독립 애니메이션 제작은 후속.
- 기존 검토 이미지·SVG는 참조 안전을 위해 그대로 보존. 최종 runtime 자산 승인 및 main 정리 미진행.

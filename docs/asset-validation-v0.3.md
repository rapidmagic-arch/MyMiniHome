## 실제 검증 방법
- ZIP 전체 76개 항목 무결성 검사 통과.
- 동물 8종 및 연못 환경 1종 × 6컷 = **54개 프레임 PNG** 파일 존재. 모든 시퀀스 내 프레임 6개는 각각 다른 파일 해시.
- 모든 프레임은 480×480px RGBA. 불투명 픽셀의 외곽 경계 비율과 프레임별 외접 경계, 시각적 차이 측정.
- 사용자가 제공한 최초 원본 시안과 새 콘셉트/시트의 외형·소품·구성을 비교. 동일한 원본 아트로 취급하지 않음.
- **실제 브라우저/ChatGPT 패널 재생은 미검증.**

## 원본 시안 대응
- **개선:** 주요 동물 8종과 연못·우체통을 포함한 자세한 새 콘셉트/프레임 시안을 생성. SVG만 있을 때보다 캐릭터 소품·표정과 숲의 분위기는 원본 방향에 가까워짐.
- **미달:** 원본과 동일한 배치·구성·상세 수준을 그대로 재현하지 않았음. 독립한 오두막·폭포·다리·식생 등의 레이어도 아직 준비되지 않음.
- **실패:** 6컷 이미지는 분리되어 있지만 캐릭터별 확정 \`durationMs\`, \`anchor\`, \`loop\` 정보와 동작별 분리는 없음. 300ms GIF는 임시보기용.
- **실패:** 개별 환경 움직임(물결·폭포·나뭇잎·굴뚝 연기·우체통)을 독립 반복 레이어로 갖추지 못함.
- **미확인:** 자연스러운 프레임 전환, 마지막→처음 연결, 브라우저 표시·성능·접근성.

## 저장소 자산 이관
- 현재 GitHub에는 **새 바이너리 PNG가 업로드되지 않았음**.
- ZIP을 로컬에서 가져올 때 \`scripts/import_review_assets.py\`를 사용: SHA-256 및 경로 검사, 기존 파일 덮어쓰기 금지.
- 보관 목적지: \`assets/review/v0.2/\` (기존 SVG 별도 유지).
- 브라우저/앱/플러그인 코드는 아직 수정·배포하지 않음.

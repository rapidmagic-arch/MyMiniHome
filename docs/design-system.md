# Pixel Forest 아트 디자인 시스템 (v0.1 / 제안 규격)

> 이 문서는 **제작 기준 제안**입니다. 최종 아트 승인·실제 기기 검증 상태가 아닙니다.

## 시각 정체성
- 밝고 포근한 숲속 AI 마을 / 도트 질감 / 귀여운 동물 / 부드러운 블록형 지형
- 지형: 2:1 아이소메트릭 투영. 캐릭터: 3/4 시점의 도트형 캐릭터
- 동일한 픽셀 윤곽선·광원 방향·조명·팔레트 규칙을 공유
- 원본 게임의 이미지나 상표를 복제하지 않고 독창적인 세계관 구성

## 자산 공통 규격
- SVG는 `viewBox`, `shape-rendering="crispEdges"`, 대체 텍스트(title/aria-label)를 포함
- 캐릭터는 **32×34 그리드 / 4배 표시 = 128×136 SVG 내재 크기**로 초기 통일
- 배경은 장면 레이어, 환경 오브젝트는 별도 레이어로 분리
- 추후 PNG로 내보낼 때 정수배 확대, nearest-neighbor, 투명 배경 준수
- 대기(Idle)/마우스 반응(Hover)/선택(Selected)은 상태 정의이며 프레임 리소스 제작은 이후 단계
- 그림자는 발밑 아래, 광원은 화면 좌상단 기준
- 배경·객체는 **클릭 가능한 캐릭터와 겹치지 않도록** 히트 영역을 화면 구현 단계에서 분리

## 동물별 대표 외형
- 다람쥐: 주황갈색, 둥글게 말린 큰 꼬리, 초록 가방
- 토끼: 아이보리색, 분홍 안쪽 귀, 푸른 목도리
- 여우: 주황색, 뾰족한 귀, 녹색 조끼
- 늑대: 회색, 파란 목도리, 작은 안경

## 기준 변경
팔레트, 그리드 또는 시점을 바꾸는 경우 전체 자산의 일관성에 미치는 영향을 먼저 확인합니다.

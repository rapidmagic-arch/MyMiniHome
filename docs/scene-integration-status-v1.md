# MyMiniHome — 8종 숲 마을 잔여 작업 통합 결과 (2026-11-24)

> **판정:** 단일 템플릿의 8종 배치·환경 효과·상호작용 구현 및 로컬 시험 **통과(범위 한정)**. **실제 ChatGPT 앱 설치·패널 렌더링·최종 아트 승인·레거시 삭제는 미완료**. 작업 완료와 제품 승인·배포를 혼동하지 말 것.

## 1. 유지한 확정 조건
- Q1~Q6 유지: 클릭 상호작용, 아이소메트릭 픽셀 숲, 기존 프로젝트/GPT URL로 직접 이동, 동물 혼합, 픽셀 프로필 팝업, ChatGPT 대화 옆 Conversation Panel 목표.
- 단일 씬 `scenes/forest-village-v1/index.html`만 갱신; 원본의 고정 배경·구조물 시안 유지.
- HTML/JSON에 실제 사용자 프로젝트/GPT URL, 계정 식별 정보·토큰을 커밋하지 않음.
- ChatGPT 기본 composer는 미니홈피에서 복제하지 않음.

## 3. 실시한 검사(혼동 금지)
### GitHub 원본 코드에 대한 모의 DOM 검증
- 8종 캐릭터 생성/클릭 8/8, 오브젝트 클릭 7/7, 우체통/물결/다리/폭포/벚꽃, 현재 세션 URL 입력·검증·호스트 열기 모의, 움직임 정지, 420px 전체보기, `reduced-motion` 테스트 통과.
- 신규 보행팩 존재 시 걷는 4종만 전용 시트 활성화, 누락 시 기존 자산 폴백 검증.
- 이 검사는 실제 브라우저의 포인터·CSS 이미지 페인팅과 구별.

### 독립 Chromium 시각 QA 미러
- 420/1024/1440px에서 **기준 배경 1 + 캐릭터 8 이미지** 정상 로딩 9/9, 환경 DOM 요소 11개(폭포 2+물결 3+꽃잎 6), JS 오류 0.
- 1440px에서 상단 폭포 CSS 프레임의 실제 값 변화, 환경 일시정지 버튼 검사.
- 이 시험 HTML은 `/mnt/data/MyMiniHome_ambient_QA_v1`에 있으며 **GitHub HTML과 동일한 HTML/CSS 바이트는 아님**. 데이터 URI 이미지를 사용한 시각 품질 참고 자료.
- 출처 이미지 ZIP의 8종 배치·색조·광원은 아직 사용자 마스터 아트 최종 승인 전.

### MCP 프로토콜 로컬 스모크 테스트
- Node 22에서 `initialize`, `tools/list`, `tools/call`, `resources/list`, `resources/read` 5건 응답 통과, `thread` 메타데이터/HTML MIME 확인.
- 리소스 시험은 작은 로컬 HTML fixture를 사용. 실제 ChatGPT에 등록해서 실행한 것이 아님.

## 4. 현재 걸림돌 및 적용 경계
1. **최종 아트 승인은 사용자 몫:** 캐릭터 8종의 배치·비율·그림자·투명 잔상/원본 마스터와의 유사성 시각 검토 필요. 색상·모션 유사도가 단순 체크만으로 승인되는 것은 아님.
2. **구조물은 베이크된 단일 배경:** 현재 폭포·나무·연못의 효과는 CSS 오버레이. **개별 구조물 PNG 재배치·물리적 흐름/나무 줄기 변형·충돌·가림을 모두 구현한 완전 분리형 렌더러는 아님**.
3. **실제 호스트 연결 미검증:** 대화 사이드 패널 진입점과 로컬 서버 코드는 작성·스모크 확인했지만, 사용자의 ChatGPT에서 플러그인 설치/연결과 화면 렌더는 확인하지 않음. 클라우드 ChatGPT는 별도 호스팅 MCP가 필요할 수 있음.
4. **실사용 링크 미입력:** 사용자별 프로젝트/GPT 주소가 제공되지 않으므로 실제 URL 매핑은 완료되지 않음. 임의로 링크를 생성하지 않음.
5. **레거시 Git main 정리는 보류:** 아직 승인된 `runtime_active` 자산셋이 없고 HTML이 review 자산을 참조함. `scripts/audit_scene_assets.py`는 **읽기 전용 현재 참조 감사**만 수행, 자동 삭제하지 않음. 최종 승인/새 경로/클론 회귀 통과 후 Git 기록 보존 조건으로 정리.

# MyMiniHome — 사용자 실행 피드백 대응: 움직임·캐릭터 클릭 수정

확인 시점: 2026-11-24  
대상: `scenes/forest-village-v1/index.html` (**기존 단일 템플릿만 변경**)  
상태: 코드 수정 및 모의 DOM 회귀 검사 통과 / 사용자 Windows 브라우저 실기 시험 대기

## 사용자 보고
> "움직임 반응 없음 클릭시 url 입력 텍스트만 뜸"

## 코드 검사에서 확인한 원인
1. 기존 `canMove=!paused&&!motionQuery.matches&&panel.hidden&&!document.hidden`에 의해 **프로필 패널이 열려 있으면 전체 이동 루프가 멈춤**.
2. `prefers-reduced-motion: reduce`가 감지되면 `toggleMotion` 버튼까지 비활성화되어 **브라우저에서 다시 재생할 수 없음**.
3. 캐릭터 클릭에서 `link:null`이므로 실제 프로젝트/GPT 이동이 불가능한데도 링크 입력 폼을 기본으로 노출해 **URL 입력만 있는 것처럼 보임**.
4. 4종 보행 순찰이 한 방향당 4.9–6.2초이고 화면이 52%로 축소되는 경우 움직임이 매우 작게 보임. 이는 **시각적인 가시성 문제의 조건부 원인**이며 실제 사용자 브라우저에서 관측한 결함으로 단정하지 않음.

## 수행한 수정
- 패널 개폐와 전체 이동 상태 분리. 프로필을 열어도 다른 동물이 움직이며 선택 캐릭터의 말풍선 위치도 이동 좌표를 따라감.
- OS 움직임 감소 설정은 최초 로드 시 존중하되, 사용자가 명시적으로 `움직임 재생`을 선택하면 해당 페이지에서 모션을 재생할 수 있게 수정(사용자 토글로 재정지 가능).
- 상단 **현재 움직임 상태와 전용 보행 이미지 로딩 수(0–4/4)**를 표시. 느린/실패한 이미지 로딩 상태 식별 가능.
- 걷는 캐릭터 4종의 기존 위치/안전구간을 유지하고 왕복 시간을 약 62%, 휴식 시간을 약 46%로 단축해 가시성 개선.
- 8종 캐릭터에 고유 인사 3개씩 총 24개를 부여. 클릭 시 **픽셀 아바타 + 인사말 + 화면 말풍선 + 짧은 흔들기 동작 + '다른 반응 보기'**를 즉시 표시.
- 링크 텍스트 입력은 **'프로젝트·GPT 링크 설정' 버튼을 클릭했을 때만** 표시. 기존 URL 미등록 상태에서는 링크 이동을 만들지 않으며 세션 메모리(Map)에서만 사용자 입력 주소를 유지.
- 캐릭터/오브젝트의 기존 클릭, 우체통 로컬 입력, 연못 물결, 폭포/꽃 효과, 화면 확대·스크롤, 현재 사용자 프로젝트/GPT 링크 수동 설정 기능 유지.

## 검증
- 연결 GitHub의 실제 HTML을 읽어 내부 JavaScript 구문 `new Function` 검사 통과.
- 동일 런타임 JS를 모의 DOM에서 실행하여 다음을 테스트.
  - 전용 보행 자산 있음: **4/4종 활성화**, 모션 상태 재생 표시.
  - 전용 보행 자산 없음: **0/4종**, 기존 제스처 이미지 폴백 상태에서도 x 좌표 변화 확인.
  - 동물 클릭: 말풍선/프로필/고유 인사 즉시 표시, URL 입력 폼 기본 숨김, 닫기/반응 변경/링크설정 토글 작동.
  - 프로필 열린 상태에서 **이미지 위치 변환값 계속 갱신**.
  - `prefers-reduced-motion: reduce` 모드: 초기 정지 문구 표시, 사용자 `움직임 재생` 클릭 후 재생 및 수동 모션 클래스 적용.
  - 우체통, 연못 클릭 반응, 링크 유효성 검사, 좁은 화면 `420px` 전체 보기 검사.
- **실제 사용자 브라우저 및 ChatGPT Conversation Panel에서 수정 후 렌더링은 아직 미검증**. 모의 DOM은 브라우저 CSS 페인팅/네트워크/실제 체감 움직임을 보장하지 않음.

## 사용자 재실행 방법
1. PowerShell: `git -C "$HOME\MyMiniHome" pull --ff-only origin main` 실행 (현재 작업 폴더에 미커밋 변경이 있다면 먼저 확인).
2. 기존 18765 서버가 MyMiniHome 리포지터리 루트에서 실행 중이라면 서버 재시작 없이 주소 `http://127.0.0.1:18765/scenes/forest-village-v1/index.html?v=motion-fix-20261124`를 강력 새로고침.
3. 상단 `움직임 재생 중 … 전용 보행 프레임 4/4종` 표시 확인. `시스템 설정에 따라 정지됨`이면 `움직임 재생` 버튼 선택.
4. 동물 클릭 시 URL 폼 없이 **인사말과 말풍선**이 먼저 보여야 함. `다른 반응 보기`를 눌러 실제로 인사가 바뀌는지 확인.
5. 재현되면 화면 상단 상태 메시지, URL, F12 Console 및 Network의 `MANIFEST.json` 요청 결과를 기록. API `/api/ai/job`, `/api/collection`은 MyMiniHome 정적 페이지의 API가 아님.

## 변경 범위·권한 경계
- 사용자 확정 Q1~Q6 변경 없음.
- 기존 `assets/review/` 및 SVG 삭제·재배포 없음.
- GitHub 링크값은 여전히 전부 `null`. 개인 링크 수동 연결만 지원.
- 프로젝트 UI 최종 승인·ChatGPT 패널 호스트 실사용 검증은 사용자 재시연 이후 별도 상태로 유지.

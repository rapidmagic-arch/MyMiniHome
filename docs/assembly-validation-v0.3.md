# MyMiniHome — 배경 자산 검증 및 조립 시험 (v0.3, 2026-11-23)

## 판정
- **전체 정적 장면을 합성하는 시제품은 가능**. 53개 분리 PNG 중 필요한 요소들과 원경 v0.1, 캐릭터 8종의 첫 프레임을 이용한 1700×1100 시험 장면 2종을 실제 합성함.
- **최종 런타임용 자산 승인은 보류**. 사용자 원본 마스터와 공통 시점·광원·픽셀 밀도·지형 높이·앵커·가림/접점 규격이 일치하는지는 확인되지 않음.
- 이번 작업에서는 `assets/runtime/`, 기존 SVG, 앱 구현/배포를 변경하지 않음.

## 실제 합성에서 드러난 문제
- 원경의 평면 목초지와 오두막/연못/폭포의 아이소메트릭 투영이 혼재. 지형 접점과 높낮이 경계가 자연스럽게 연결되지 않음.
- 소품 일부가 지면에 안착하지 않고 떠 보임. 강·연못과 폭포의 수위/흐름이 연결되지 않음.
- 일괄 배치 기준(발 위치/그림자)이 없고, 캐릭터 크기·가림 순서가 임시값이어서 마스터 장면과 비율이 다름.
- 현재 결합은 **이미지 합성 가능성 확인용**이지, 클릭/프로필 UI/애니메이션의 상호작용 구현이 아님.

## 런타임 조립 전 필수 작업
1. 원본 마스터에 맞춘 **공통 씬 좌표계/카메라(아이소메트릭 2:1), 타일 footprint, 앵커, 캐릭터 스케일** 확정
2. 가장자리 38개 후보 분류, 실제 할로/잔상/잘림 자산의 재정제 또는 재생성
3. 지형 타일 모서리/물길/다리 발판 연결과 가림·그림자 규칙 검증
4. 하늘/산/숲 레이어 분리 및 폭포·연못·나뭇잎·우체통 루프 프레임 제작
5. 실제 패널 화면 조립 후 클릭 영역/애니메이션/성능/가독성 검증

**이 문서는 작업 수행 및 정적 합성 검증 결과이지, 원본 디자인 재현 완료나 제품 완성 선언이 아니다.**

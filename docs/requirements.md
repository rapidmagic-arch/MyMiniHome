## 고정된 시각 방향
밝은 숲, 연못, 블록형 지형 느낌, 동물 캐릭터(다람쥐·토끼·여우·늑대), 우체통과 환경 오브젝트.

## 설계와 구현의 경계
- ChatGPT의 기본 채팅 UI는 플러그인이 재구현하지 않습니다.
- 프로젝트 링크 열기와 프로젝트 내부 **신규 대화 자동 생성**은 다릅니다. 자동 생성은 확정 범위가 아닙니다.
- GPT/프로젝트의 실시간 메타데이터 동기화는 확정 범위가 아닙니다.
- 프로젝트 및 GPT URL은 개인 정보를 포함할 수 있으므로 공개 저장소에 실제 주소를 넣지 않습니다.
- 이 저장소의 현재 자산은 콘셉트 및 UI 목업용이며 ChatGPT 호스트 연동은 미검증입니다.

## 2026-11-25 캐릭터 클릭·충돌 방지 동작 변경 (이전 Q5의 호출 조건보다 우선)

- **클릭/터치 1회:** 캐릭터를 데롱데롱 들어 올린다. 프로필은 자동 열지 않는다.
- **동일 캐릭터 지점을 빠르게 두 번 클릭/터치:** 기존 좌측 하단 픽셀 프로필을 표시한다. Q5의 **프로필 UI 자체는 유지**하고 호출 조건만 변경한다.
- **다른 캐릭터 선택:** 현재 들고 있는 캐릭터를 취소하고 새로운 캐릭터를 들어 올릴 수 있다.
- **두 번째 장소 클릭:** 이동 가능 영역이면서 다른 캐릭터가 차지하지 않은 곳에 착지한다.
- **같은 길의 만남:** 가만히 있는 동물은 다른 동물에게 밀리지 않고, 다가오는 동물은 멈춤·인사 또는 이동 가능한 길로 우회한다. 앞뒤 깊이 표시는 발 위치를 기준으로 처리한다.
- **세부 구현 값(권고):** 빠른 두 번 터치 간격 340ms, 화면 거리 26px, 근사 충돌 영역 등은 기존 요구를 구현하기 위한 시제품 설정이며 고정된 사용자 요구 수치가 아니다.

## 1. 의견도출(가상 전문가 관점, 실제 독립 전문가 리뷰 아님)

| 관점 | 판단 | 채택한 수정 |
| --- | --- | --- |
| UX·교육 이용자 관점 | 클릭·프로필과 들기 충돌이 가장 큰 위험. 클릭/터치에서 같은 규칙을 사용하는 것이 중요 | 첫 클릭에 프로필+들기 동시 시작, 두 번째 장면 클릭은 착지 우선, Esc 취소. 명시적 도움말과 착지 구역 강조 |

| 유지보수·호스트 | 실제 ChatGPT 내 앱 실행은 로컬 stdio MCP와 별개. 작은 PiP와 큰 전체화면이 같은 콘텐츠 사용 | 기존 단일 HTML 유지, MCP 리소스에 inline/pip/fullscreen 지원 모드 메타데이터 추가. 실제 연결·호스트 렌더링은 미검증 |

**중요한 절충:** 기존 4종 보행용 6프레임 이미지가 있는 동물만 실제 걷기 프레임을 사용한다. 나머지 4종은 재배치 후 짧은 좌우 이동 및 제자리 모션으로 폴백한다. 모든 캐릭터가 동일한 걷기 품질이라고 주장하지 않는다.

## 2. 실제 소스에서 식별한 문제와 수정

1. **보행 위치·클릭 범위 불일치**: 기존 코드는 중앙에 고정된 클릭 버튼 내부 이미지만 이동시켜 보이는 동물과 클릭 영역이 어긋났다. 수정: actor 버튼의 `left/top`을 실제 이동 좌표에 동기화.
2. **사용자 요구와 클릭 동작 충돌**: 기존 클릭은 프로필만 열었다. 수정: `ROAMING → CARRIED → LANDING → ROAMING`을 원칙으로 첫 클릭 프로필 열기와 들기 동시 실행. 두 번째 장면 클릭의 이벤트 캡처가 착지 판단을 우선 처리.
3. **무제한 위치 이동 위험**: 배경이 하나의 그림이므로 건물·물 위를 단순 좌표만으로 구별하지 못한다. 수정: 배경 좌표의 4개 육지 영역과 1개 연못 영역을 안전 착지 후보로 지정. 개구리는 물, 다른 캐릭터는 육지 사용. 이 영역은 첫 번째 시안이며 실제 아트 검수 필요.
4. **새 위치에 착지한 뒤 순간 위치 이동**: 기존 왕복 보행 위상 기준으로 점프할 위험. 수정: 착지 순간의 `track(clock)` 좌표에서 오프셋을 계산해 첫 렌더 좌표가 착지 위치와 일치하도록 보정.
5. **스크롤 문제**: 너비만 계산하고 기본 52% 최소 배율 때문에 작은 화면에서 수평 스크롤. 수정: 너비와 가용 높이를 함께 이용해 **기본 전체 보기**, 사용자가 명시적으로 확대하면 스크롤을 허용.
6. **오디오 없음**: 신규 WebAudio 합성 효과음 및 오리지널 소규모 BGM 3곡 + 파일 기반 플레이리스트 `assets/audio/bgm/playlist.json`; 최초 재생은 버튼 클릭.
7. **이야기 진행 불가**: 기존 인사만 교체. 수정: 8종 캐릭터 및 7개 장소에 사전 작성 단문 스토리 단계와 '이야기 계속' 버튼.
8. **ChatGPT 표시 모드 설정 미비**: MCP 리소스에 `_meta["openai/ui"].availableDisplayModes=["inline","pip","fullscreen"]` 추가, 실제 호스트 API 있을 때만 모드 변경 버튼 표시.

## 3. 검증 근거

- 연결 GitHub에서 최신 장면 HTML과 실제 JS 파싱에 성공.
- 동일 JS를 가짜 DOM과 Web Audio 노드, 로딩 성공·실패를 모의한 실행에서 캐릭터 들기·무효 착지·유효 착지·이동 재개·스토리 진행·BGM 켜기/정지/곡 전환·효과음 제어·연못/우체통·가로세로 배율을 검사, **결과 PASS**.
- 저장소에 `scripts/test_scene_runtime.cjs` 추가: Node 22에서 `node scripts/test_scene_runtime.cjs`로 같은 유형의 의존성 없는 모의 회귀 테스트 실행 가능.
- 기존 이미지 경로와 캐릭터 8종, 오브젝트 7곳을 보존.
- **미수행:** 실제 Windows/Chrome 화면 클릭·드래그, Android/iPad 터치, 실제 스피커 BGM 음질·재생, OS reduced-motion 전체 조합, 파일 MP3/OGG 실제 재생, ChatGPT 플러그인 설치 및 PiP/Fullscreen 전환.
- **라이선스:** 외부 무료 BGM 파일을 수집하거나 라이선스 허가를 추정하지 않았다. 내장 3곡은 런타임 자체 합성 시퀀스이며 일반 상용 음원 품질을 주장하지 않는다. 파일 플레이리스트는 사용 권한 확인 후 사용자가 추가.
- **아트 한계:** 걷기 4종 및 환경 효과는 기존 리뷰 자산으로 남아 있고, 최종 아트 승인 전에는 `prototype_not_approved` 유지.

# 이미지 자산 관리 및 검토 기준

## 제작 원칙
1. 숲과 연못의 콘셉트 이미지를 먼저 정하고, 캐릭터 및 오브젝트의 외곽선·시점·색상 규칙을 맞춥니다.
2. 클릭 대상(캐릭터·우체통 등)과 배경을 분리해 각 자산을 독립적으로 버전 관리합니다.
3. AI 이미지 생성 결과는 **콘셉트**입니다. 자동으로 픽셀 정합성·투명 스프라이트가 확보되었다고 가정하지 않습니다.
4. 스프라이트를 사용하기 전 그림자·윤곽선·시점·배경 투명도·캔버스 크기를 검사합니다.
5. 최종 캐릭터 ↔ GPT/프로젝트 매핑은 실제 사용자가 확인한 대상과 링크를 이용합니다.

## 파일 구분
- `assets/characters/`: 동물 프로토타입 스프라이트
- `assets/environment/`: 장면·나무·연못·타일
- `assets/objects/`: 우체통 등 대화 외 상호작용 요소
- `assets/manifest.json`: 자산 종류·경로·상태

## 기본 확인 항목
- SVG가 문법적으로 유효하고 브라우저에서 정상 표시되는가?
- 동일 캐릭터 계열에 과도한 해상도·윤곽선·광원 차이가 없는가?
- 배경과 클릭 대상이 별도 파일로 유지되는가?
- 화면 확대 시 픽셀의 경계가 뭉개지지 않는가?
- 저작권 문제 있는 타인의 자산을 복제하지 않았는가?
- ChatGPT 링크/계정 식별 정보가 공개 저장소에 포함되지 않았는가?

## 상태 정의
- `prototype`: 목업·검토용, 최종 품질/시스템 연동 미확인
- `approved`: 디자인 승인, 별도의 브라우저/호스트 검증이 필요할 수 있음

이번 자산은 모두 `prototype`입니다.

# MyMiniHome — 보행 전용 캐릭터 자산 제작 및 접지 검증 v0.1
작성: 2026-11-24

## 목표와 기준
현재 유효한 Q1~Q6, 단일 템플릿 `scenes/forest-village-v1/index.html` 유지. 이전 캐릭터 6프레임은 제스처·점프가 섞여 보행으로 부적합하여, **다람쥐·토끼·여우·늑대 4종의 보행 전용 프레임**을 신규 제작·정렬함. 기존 PNG/SVG 삭제/교체 없음.

## 제작 결과
- 이미지 생성 후보 4장 중 한 장의 1536×1024 RGBA 합성 시트를 원본으로 선택. 한 캐릭터당 3×2 = 6개의 우측 진행 프레임.
- 알파>128 픽셀의 연결된 주체를 **24개** 검출해 인접 캐릭터 간 누락·섞임 없이 분리. 각 프레임 안의 이미지 안티앨리어싱을 보존함.
- `256×256` 고정 크기 RGBA 자산, 공통 앵커 `(128, 230)`(`x=0.5,y=0.8984375`). 좌우 반전으로 왼쪽 방향도 생성해 **48개 PNG**.
- 지면(발) 하단 바운딩 위치 편차 **0px**, 몸체 바운딩 중심 편차 **최대 1px**, 캔버스 외곽 불투명 픽셀 접촉 **0개**.
- 정렬된 6개 프레임과 녹색 배경을 합성한 실제 보행 미리보기 4종 `GIF`, 검수용 `CONTACT_SHEET.jpg`, 원본 `source/walk_sheet_source.png`, 파일별 SHA-256/크기/앵커를 가진 `MANIFEST.json`, `QA_REPORT.md` 제공.

### 정적 루프 접합 지표(측정값, 시각적 승인 아님)
프레임을 동일 배경 위에 배치해 연속 프레임 간 평균 절대 화소 차이를 측정. `frame6→1` 전환의 차이 ÷ `frame1→2…5→6` 값의 중앙값:
- 다람쥐 **0.99**, 토끼 **1.11**, 여우 **0.68**, 늑대 **0.98**.
- 이 지표는 루프 경계에서 유독 큰 픽셀 변화가 있는지를 확인하는 **보조지표**이며, 실제 걷기 유사도/관절 타이밍 통과 근거는 아님.

## 브라우저 시범 장면 검증
- 검증 범위: 로컬 QA HTML(기존 숲 마을 배경에 신규 스프라이트 4종을 겹쳐 정해진 짧은 이동 경로 실행). **GitHub HTML을 실제 호스팅해 로드한 시험은 아님.**
- headless Chromium + Playwright, 파일 네비게이션 제한을 피하기 위해 48개 자산 및 배경을 **data URI**로 제공하여 검증.
- 1440px / 1024px / 420px에서 캐릭터 4개 모두 이미지 로드; 진행 중 프레임 전환 확인; JavaScript 페이지 오류 0; 1440px에서 실제 포인터 클릭 팝업 테스트; 420px에서 전체보기 토글과 가로 스크롤 확인; `prefers-reduced-motion: reduce` 설정 시 프레임 1 고정 확인.
- 실제 브라우저 정적 스크린샷은 대화의 `MyMiniHome_walk_browser_QA/`에 별도 제공. **실제 연속 동작의 자연스러움은 추가 사용자 시각 평가 필요**.

## 기존 템플릿에 적용한 변경
- `scenes/forest-village-v1/index.html`에 **선택적 보행 자산 로더** 적용.
- `../../assets/review/walk-v0.1/MANIFEST.json`이 존재하고 `status=REVIEW_CANDIDATE_NOT_APPROVED`, `count.totalPngs=48`이면 모든 좌/우 프레임을 미리 로드하고, 성공한 캐릭터별로 새 보행 프레임을 사용.
- 새 48개 이미지가 아직 업로드되지 않았거나 일부 파일이 누락된 경우, 기존 `assets/review/v0.2` 제스처 프레임으로 **안전하게 폴백**. 실제 이미지 참조 경로의 손상 방지.
- 새 보행 시트가 활성화되면 프레임 160ms 간격 순환, 좌/우 방향 자산 선택. 불필요한 CSS 보브(떠 보임)를 배제하고 고정 접지점 사용. 기존 안정적인 클릭 히트박스는 유지.
- 모의 DOM 스크립트 검증: 자산 없음 모드에서 4종 모두 `legacy-gestures`, 48개 이미지 준비된 모드에서 `walk-v0.1-candidate` 진입 확인. 이 테스트는 **실제 GitHub 배포 브라우저가 아님**.

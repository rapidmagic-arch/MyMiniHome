# MyMiniHome — 클릭 분리 및 캐릭터 간 충돌 방지 리뷰 (2026-11-25)

## 적용 범위
- 기준: 단일 `scenes/forest-village-v1/index.html`, version `scene-v1-encounter-interaction-prototype`
- 사용자 결정: 클릭 1회 → 들어 올리기, 같은 캐릭터 2회 클릭 → 기존 좌측 하단 상세 패널. 같은 길에서 접근하면 정지 캐릭터가 밀리지 않고, 걷는 캐릭터가 멈춤·인사·가능한 경우 우회. 이미 다른 캐릭터가 있는 위치에 착지 금지. 앞뒤 자연스러운 겹침 표현.
- 기존 8종 캐릭터, 7곳 오브젝트, 숲 배경 1종, ChatGPT 앱 목표, URL 수동 연결, 음악·스토리 기능 유지.
- 상태: 구현 및 모의 DOM 회귀 검증 통과, 실제 사용자 Windows Chrome·태블릿·ChatGPT 호스트 UI 실기 검증 미완료.

## 확인된 이전 코드 문제
1. `pickUpActor()`가 `openInfo()`를 무조건 호출해 단일 클릭에서도 상세 패널이 나타났음.
2. `.is-carried`에 `pointer-events:none`이 적용되어 캐릭터에 `dblclick`만 추가하는 방식은 두 번째 클릭 대상이 바뀌어 실패할 수 있음.
3. 모든 캐릭터의 위치를 독립적으로 갱신하여 상호 위치 확인 없이 통과하거나 겹칠 수 있었음.
4. 재배치한 제자리 동물에게 `Math.sin(...)*14`의 좌우 드리프트가 적용돼 다른 동물이 밀어 낸 듯 보일 수 있었음. 실제 상대 캐릭터를 이동시키는 push 물리 엔진은 없었음.
5. 기존 고정 `z-index`는 Y 방향의 앞뒤 깊이를 반영하지 않았음.

## 변경된 동작·조건
| 이벤트 | 동작 및 부정 조건 |
| --- | --- |
| 캐릭터 1회 클릭/터치 | `ROAMING → CARRIED`로 전환. 프로필은 자동 표시하지 않음 |
| 동일 캐릭터 지점에 340ms 이내·화면 좌표 26px 이내 다시 클릭/터치 | 들기 취소 후 기존 좌측 하단 프로필 표시. DOM `dblclick`에 의존하지 않음 |
| 다른 캐릭터 클릭 | 기존 들기 취소 및 새 캐릭터 들기. 이미 앉아 있는 곳으로 착지하지 않음 |
| 유효한 빈 착지 위치 선택 | `LANDING → ROAMING`; 동물의 새 위치를 갱신하고 이동 재개 |
| 이동 불가 지형 또는 캐릭터가 차지한 지점 선택 | 착지를 거절하고 들고 있는 상태 유지. 이용자가 다른 위치 선택 가능 |
| `Esc` | 들기 취소. 직전 위치로 복귀, 기존 프로필이 있으면 별도 닫기 |
| 이동자가 정지 캐릭터 또는 다른 이동자에게 접근 | 보행자만 진행을 멈추거나 유효한 옆 경로를 이용. 상대 캐릭터 좌표를 밀어내지 않음 |
| 지나갈 경로가 없는 경우 | 임의 밀기/관통 대신 정지해 기다림 |
| 만남이 감지된 경우 | 약 1.7초 동안 짧은 인사말과 기존 합성 효과음. 같은 쌍의 메시지 반복은 일정 시간 제한 |
| 서로 화면에서 겹칠 때 | 발 위치의 Y좌표에 따른 레이어 우선순위 변경. 들고 있는 캐릭터와 말풍선은 별도 우선순위 |

캐릭터 이동은 전용 프레임이 있는 4종을 기준으로 처리하고, 전용 걷기 프레임이 없는 4종은 원래 자리에서 제자리 동작을 유지한다. 모든 캐릭터가 같은 품질의 걷기 동작을 사용한다는 뜻은 아님.

## 충돌 회피의 계산 범위
- 픽셀 그래픽의 실제 충돌 마스크가 아니라 **발 위치 중심의 간단한 가로·세로 거리 근사**를 사용한다. 캐릭터 크기를 기준으로 안전 거리 계산.
- 육지·연못의 기존 유효 이동 구역을 넘지 않는 후보 우회 경로만 허용.
- 이동 중 정지가 발생하면 해당 동물의 보행 시계(`moveClock`)를 멈춰 시간 진행으로 순간 이동하지 않게 함.
- 우회 시 세로 방향으로 천천히 이동하고 장애물을 지나간 뒤 원래 길로 돌아오도록 함.
- 실제 마스터 배경에서 꽃, 나무뿌리, 다리 난간 등 복잡한 장애물을 완벽하게 인지하는 **경로 탐색/물리 엔진은 아님**. 시각 검수 후 거리와 구역의 조정 여지 있음.

## 검증 및 경계
- GitHub의 실제 scene HTML JavaScript를 파싱.
- `scripts/test_scene_runtime.cjs` 실행 시의 모의 DOM 시나리오: 단일 클릭·동일 캐릭터 빠른 2회 클릭·다른 캐릭터로 전환·무효 지형/점유 지점 착지 거부·착지 후 보행·Escape 취소·기존 음악/스토리/반응형 기능 검증.
- 모의 DOM 충돌 시나리오: 곰을 길 근처에 착지시키고 이동 캐릭터의 접근을 시뮬레이션. 곰 좌표 고정, 이동 캐릭터의 Y 방향 우회, 인사말 노출, 충돌 판정 범위 내 겹침 0건 확인.
- 기존 이미지와 폴더 구조를 유지. ChatGPT MCP 호스트 설치·배포, 실제 브라우저 터치, 시각적 이동 자연스러움, 실제 소리 재생과 아트 최종 채택은 아직 실측/검증 전.
- **최종 승인 상태는 여전히 `prototype_not_approved`**이며, 사용자가 실제 브라우저에서 결과를 확인해야 한다.

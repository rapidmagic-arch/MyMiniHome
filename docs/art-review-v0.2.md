# MyMiniHome v0.2 아트 자산 인계 상태 (2026-11-23)

## 목적
사용자 제공 원본 시안의 디테일과 '살아 있는 숲' 요구를 충족하기 위해, 정적 SVG 9종을 바로 채택하지 않고 **풍부한 콘셉트 아트 → 동물별 시간 프레임 → 투명 배경 검토 → 통합 장면 검증** 순으로 개선합니다.

## 이번 세션에서 생성한 초안
- 신규 숲 마을 콘셉트 이미지 1종
- 동물 8종(다람쥐, 토끼, 여우, 늑대, 부엉이, 곰, 개구리, 고슴도치) 각 6컷 시트: 총 48컷
- 숲·연못 환경 6컷 시트: 총 6컷
- 검토용 프레임 PNG 54개 분할, 임시 미리보기 GIF 9종
- ChatGPT 대화의 ZIP 검토 패키지 **MyMiniHome_asset_review_v0.2.zip** 생성

**중요:** 이 PNG/ZIP은 현재 GitHub 리포지터리에 포함되지 않았습니다. ChatGPT 세션의 다운로드 결과물로 별도 전달했습니다. 이 문서가 PNG 업로드 완료를 뜻하지 않습니다.

## 디자인 원본과 상태
- 사용자 업로드한 기대 시안을 비주얼 비교 기준으로 유지합니다.
- 새 콘셉트 이미지는 변경 시안이며 아직 사용자 승인·확정 아트가 아닙니다.
- 생성형 시트는 3열×2행, 각 셀 512×512px, 검토용 분할 프레임은 셀 가장자리 16px을 제거해 480×480px로 추출했습니다.
- 밝은 크림색 바탕 제거는 가장자리 연결 색상을 기준으로 자동 처리했으므로 털·몸체·그림자 경계에 결함 가능성이 있습니다.
- 300ms/프레임 GIF는 **보기용 임시 재생 속도**이고 사용자 확정 타이밍이 아닙니다.
- 프레임별 캐릭터 앵커(발 위치), 동작 연속성, 순환 연결, 브라우저 결과, ChatGPT 패널 동작은 **미검증**입니다.

## 저장소 반영 권고 위치 (미적용)
```text
assets/
  concepts/            # 비교 시안/마스터 이미지 (최종 승인 전 구분)
  characters/<id>/
    source-sheet.png    # 생성 시트 원본
    frames/01.png ...   # 검토 후 정제된 투명 프레임
    animation.json      # 순서, duration, loop, anchor
  environment/
    ...
```
기존 `assets/characters/*.svg`는 즉시 덮어쓰지 않고 구형 프로토타입으로 식별·유지합니다.

# MyMiniHome 보행 전용 스프라이트 1차 QA — v0.1

## 결과 및 범위
- 이미지 생성 결과(알파 채널 포함)에서 4종(다람쥐, 토끼, 여우, 늑대) × 6개 보행 포즈를 분리. 각 포즈의 좌우 반전을 별도 저장하여 **48개 256×256 RGBA PNG** 생성.
- 모든 그림의 alpha>128 연결 픽셀 중 주체 24개를 확인하고 위치를 추출함. 타 캐릭터 오브젝트와 다른 조각이 섞이지 않도록 연결요소별로 마스킹함.
- (128,230) 고정 기준 발 접지 좌표에 24개 정방향 프레임을 정렬하고 왼쪽 거울 프레임을 생성.
- 이 결과는 **독립 PNG 자산 및 정적 앵커 보정 완료**이지 실제 보행 연출이나 ChatGPT 패널/사용자 미술 승인 완료가 아님.

## 자동 검사
| 대상 | 바운딩박스 중심 편차 px | 하단 편차 px | 이미지 캔버스 외곽 불투명 픽셀 최대 | 
|---|---:|---:|---:|
| squirrel | 0.5 | 0 | 0 |
| rabbit | 1.0 | 0 | 0 |
| fox | 1.0 | 0 | 0 |
| wolf | 0.5 | 0 | 0 |

- 분리된 프레임 PNG: 48개 (left 24 + right 24).
- RGBA 및 완전 투명 픽셀: 모두 확인.
- 캔버스 경계에 alpha>128 픽셀 접촉: 0개.
- 전체 24개 원본 컴포넌트 추출: 24개.

## 품질 보류 항목
1. 이미지 생성 프레임 6개가 **원본 마스터 캐릭터와 동일한 복장·표정인지** 비교 필요. 생성형 이미지에서 가방 장식·수건·표정 등이 약간 다를 수 있음.
2. 6->1 루프와 캐릭터가 실제 장면 내 이동할 때 발이 미끄러져 보이지 않는지 **브라우저/육안 검증** 필요.
3. 왼쪽 이동은 이미지 수평 반전이므로 비대칭 가방·휘장 등의 방향이 바뀜. 수용 가능한지 사용자 검토 전까지 최종 승인 금지.
4. 캐릭터 옆으로 걷는 포즈는 현행 3/4 시점과 정확히 동일하지 않을 수 있음.
5. 신체 그림자와 발이 특정 프레임에서 겹칠 수 있어 실제 장면에서는 중복 CSS 그림자 적용 주의.

## 사용 가이드
- 프레임 경로: `frames/{id}/{id}_walk_{direction}_01.png` ~ 06.png
- 실제 장면 적용 시 원본 `assets/review/v0.2`는 유지하고, 새 경로는 **GitHub에 업로드 검증된 뒤 참조 변경**.
- 화면상 sprite anchor: (0.5, 0.8984375), 프레임별 보정 불필요하도록 만든 정규 캔버스.
- 보행 재생 속도 시범: 160ms/frame. 실제 이동 속도와 조화 검증 필요.

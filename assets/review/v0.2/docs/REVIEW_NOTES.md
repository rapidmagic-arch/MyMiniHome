# MyMiniHome · 자산 리뷰 패키지 v0.2 (2026-11-23)

## 포함 내용
- `concept/village_master_concept.png`: 새 숲 마을 콘셉트 1종(참고 시안; 사용자 제공 원본을 교체하는 승인본 아님)
- `sheets/`: 캐릭터 8종 + 연못·숲 환경 1종의 3×2 이미지 시트
- `frames/<id>/`: 각 시트에서 6개 셀을 개별 프레임으로 분리한 PNG (총 54개)
- `previews/`: 프레임 재생 순서를 확인하는 임시 GIF와 첫 프레임 한눈보기
- `manifest.json`: 파일 경로와 미검증 사항 기록

## 검증과 제한
1. 원본 시트는 보존. 프레임은 3열×2행 512×512px 셀에서 바깥 16px을 제외하고 480×480px로 추출.
2. 밝은 크림 배경은 가장자리에서 이어진 영역에 한해 휴리스틱 방식으로 투명화. 누락·테두리 잔여·머리카락/털 가장자리 문제는 수동 확인 필요.
3. 프레임별 캐릭터의 발 위치·몸 크기·손/소품 위치가 정확히 일치하는지는 아직 검증되지 않음.
4. GIF는 300ms/프레임의 **임시 확인용**. 이 값은 사용자 확정 타이밍이 아니며 반복 재생이 자연스럽지 않을 수 있음.
5. 이미지 시트는 생성형 AI의 콘셉트 아트에서 분할한 것으로 **실제 제품 수준의 픽셀 스프라이트를 검증 완료했다는 뜻이 아님**.
6. ChatGPT Conversation Panel, 클릭/팝업 UI, JavaScript 애니메이션 실행 및 배포는 이 패키지에 없음.
7. GitHub 리포지터리에 PNG 파일 반영은 완료되지 않음. 저장소의 기존 SVG 원본을 덮어쓰지 말 것.

# MyMiniHome — Pixel Forest AI Village

ChatGPT 기본 대화창 옆의 **아이소메트릭 픽셀 숲 마을**을 목표로 하는 프로젝트입니다.

> **현재 판정(2026-11-25):** `scene-v1-playful-widget-draft` — 기존 단일 장면에 캐릭터 들기·매달림·안전 착지·새 위치 활동, 스토리, 내장 합성 BGM 3곡/효과음, MP3 폴더 플레이리스트, 가로·세로 자동 맞춤을 **코드 구현**했습니다. 가상 DOM 회귀 시험을 통과했으나 **실제 Chrome/태블릿 음향·화면 및 ChatGPT 앱 연결은 아직 미검증**입니다. 상태는 계속 `prototype_not_approved`입니다.

## 구현된 단일 장면
- **마스터:** 1774×887 고정 배경 콘셉트. 오두막·다리·폭포·연못 등은 원본 이미지 내 고정.
- **8종 동물:** 다람쥐·토끼·여우·늑대(보행 프레임) + 부엉이·곰·개구리·고슴도치(제자리 반응).
- **7개 핫스팟:** 오두막, 독서 쉼터, 우체통, 다리, 연못, 폭포, 벚꽃나무.
- **환경 효과:** 폭포 물줄기 2곳, 연못 물결 3곳, 벚꽃잎 6개, 우체통 반응. 독립 CSS 오버레이 시제품.
- **입력/링크:** 우체통의 한 줄 입력은 화면 안에서만 미리보기. 실제 GPT·프로젝트 URL은 동물 프로필에서 **사용자가 직접 임시로 입력**하며 공개 Git에 저장하지 않음.
- **캐릭터 이동:** 첫 클릭 시 매달림, 두 번째 클릭 시 이동 가능 영역에 착지, 기존 동물 4종은 보행 프레임 재개·나머지는 좌우 제자리 반응 폴백.
- **음악·효과음:** 내장 자체 합성 BGM 3곡 반복, [폴더 플레이리스트 생성](assets/audio/README.md), 캐릭터·장소별 합성 효과음. 실제 MP3 파일은 제공되지 않음.
- **이야기:** 동물 8종·장소 7곳에 짧은 연속 스토리, '이야기 계속' 버튼.
- **반응형:** 기본 너비·높이 전체 맞춤, 사용자 확대 시 스크롤 허용, 모션 정지·움직임 감소 설정.
- **MCP:** 로컬 Node 22 `stdio` 서버에 ChatGPT `thread` UI 진입점 메타데이터 포함. **실제 호스트 연결은 검증 전.**

## 검증 및 개발 기준
- GitHub 장면이 참조하는 이미지/매니페스트 **98개 경로 누락 0개**(2026-11-24).
- **최신 회귀 시험:** `node scripts/test_scene_runtime.cjs` (Node 22, 의존성 없음). 해당 테스트 로직을 현재 GitHub HTML 소스로 모의 실행해 들기·착지·스토리·BGM·반응형 상태 PASS. 실제 브라우저·오디오 출력 시험과는 구분.
- 초기 모의 DOM 이력: 캐릭터 8종·핫스팟 7곳·보행 자산/폴백·개인 URL 임시 입력·모션 제어 검증.
- 독립 Chromium QA 미러: 420·1024·1440px에서 배경+8종 로드, 환경 오버레이·일시정지 확인. **실제 GitHub HTML 동일 바이트 / ChatGPT 패널 시험은 아님.**
- 기존 review 이미지/SVG는 현재 HTML 참조와 최종 채택 상태 확인 전이므로 **보존 중**. 자동 삭제 금지; `scripts/audit_scene_assets.py`는 읽기 전용 참조 점검.

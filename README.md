# MyMiniHome — Pixel Forest AI Village

ChatGPT 네이티브 대화창 옆에서 여는 **아이소메트릭 픽셀 숲 미니홈피** 프로젝트입니다.

> 현재 단계: **디자인 자산 및 저장소 초기 구성**. 웹 UI, MCP 서버, ChatGPT 패널 연결, 배포는 아직 구현하지 않았습니다.

## 확정 요구사항 (Q1–Q6)
- **Q1-B:** 상호작용형 미니홈피
- **Q2-C:** 아이소메트릭 픽셀 아트
- **Q3-A:** 기존 ChatGPT 프로젝트·GPT로 직접 이동
- **Q4-C:** 프로젝트와 GPT를 대표하는 동물 캐릭터 혼합
- **Q5-C:** 캐릭터 클릭 시 미니홈피 스타일 프로필 팝업
- **Q6-A:** ChatGPT 내부 플러그인/Conversation Panel 사용

세계관은 밝은 숲, 연못, 블록형 지형과 친근한 동물 캐릭터입니다. 기존 Minecraft 에셋은 복제하지 않습니다.

## 저장소 운영
디자인 원본, 소스, 설정의 기준 저장소는 GitHub입니다. ChatGPT 작업 공간은 제작·검토에 사용합니다.
공개 저장소이므로 개인 프로젝트 링크, 계정 정보, 토큰, 비공개 자료를 **커밋하지 않습니다**.

초기 SVG는 **일관성 검토와 UI 목업을 위한 프로토타입 자산**이며, 최종 아트 승인이나 호스트 동작 검증을 뜻하지 않습니다.

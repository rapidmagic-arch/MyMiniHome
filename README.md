# MyMiniHome — Pixel Forest AI Village

ChatGPT 네이티브 대화창 옆에서 여는 **아이소메트릭 픽셀 숲 미니홈피** 프로젝트입니다.

> 현재 단계: **디자인 자산 및 저장소 초기 구성**. 웹 UI, MCP 서버, ChatGPT 패널 연결, 배포는 아직 구현하지 않았습니다.

## 확정 요구사항 (Q1–Q6)
- **Q1-B:** 상호작용형 미니홈피
- **Q2-C:** 아이소메트릭 픽셀 아트
- **Q3-A:** 기존 ChatGPT 프로젝트·GPT로 직접 이동
- **Q4-C:** 프로젝트와 GPT를 대표하는 동물 캐릭터 혼합
- **Q5-C:** 캐릭터 클릭 시 미니홈피 스타일 프로필 팝업
- **Q6-A:** ChatGPT 내부 플러그인/Conversation Panel 사용

세계관은 밝은 숲, 연못, 블록형 지형과 친근한 동물 캐릭터입니다. 기존 Minecraft 에셋은 복제하지 않습니다.

## 저장소 운영
디자인 원본, 소스, 설정의 기준 저장소는 GitHub입니다. ChatGPT 작업 공간은 제작·검토에 사용합니다.
공개 저장소이므로 개인 프로젝트 링크, 계정 정보, 토큰, 비공개 자료를 **커밋하지 않습니다**.

초기 SVG는 **일관성 검토와 UI 목업을 위한 프로토타입 자산**이며, 최종 아트 승인이나 호스트 동작 검증을 뜻하지 않습니다.

## 현재 진행 작업 — 기본 장면 1종 (2026-11-23)
- [작동하는 장면 미리보기 HTML](scenes/forest-village-v1/index.html): 마스터 배경 + 캐릭터 4종 + 클릭 핫스팟·프로필 팝업. **시제품이며 최종 채택/ChatGPT 패널 연동 전**.
- [조립 순서·품질 기준·다음 회차 연결 기록](docs/scene-assembly-workflow.md): 지형 접지, 스케일, 앵커, 레거시 자산 정리의 조건부 제안.
- **레거시 자산 삭제는 아직 수행하지 않았습니다.** 현재 HTML이 참조하는 `assets/review/` 파일을 제거하면 미리보기가 깨집니다. 최종본 채택과 참조 경로 변경/검증 후 정리 여부를 결정합니다.

## 캐릭터 움직임·상호작용 추가 (2026-11-23)
- [단일 숲 마을 템플릿](scenes/forest-village-v1/index.html): 기존 템플릿에 동물 4종의 제한된 왕복 이동(6개 후보 프레임), 오브젝트별 반응 5종, 전체보기/확대보기 및 모션 정지, 로컬 메모 미리보기 기능 추가.
- [장면 동작 명세 및 테스트 한계](docs/scene-interaction-spec-v1.md): 화면 크기·ChatGPT 대화와 미니홈피 입력의 역할 구분·QA 체크리스트.
- **현재 상태:** 정적 자산 조립 시안 + 상호작용 **프로토타입**. 실제 브라우저 시각/ChatGPT 호스트 검증과 최종 아트 승인은 별개. 검토·레거시 이미지 삭제는 수행하지 않음.
